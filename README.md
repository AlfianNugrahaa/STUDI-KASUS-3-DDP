1. **# 1. Instalasi/input nilai ujian mahasiswa**
   Menentukan batas nilai **65–100** dan menyiapkan tempat untuk menyimpan seluruh nilai, nilai lulus, dan nilai remedi.

2. **# 2. Perulangan input nilai/data mahasiswa**
   Meminta pengguna memasukkan nilai mahasiswa satu per satu. Input akan terus berjalan sampai pengguna mengetik **`selesai`**.

3. **# 3. Menghapus input nilai/data**
   Digunakan untuk menghapus nilai yang sudah dimasukkan apabila terdapat kesalahan data.

4. **# 4. Validasi input nilai ujian mahasiswa dan pengelompokan nilai**
   Memeriksa apakah nilai yang dimasukkan valid, yaitu **0–100**. Setelah itu, nilai dikelompokkan menjadi **LULUS jika ≥65** dan **REMEDI jika <65**.

5. **# 5. Menampilkan seluruh nilai ujian mahasiswa**
   Menampilkan hasil akhir berupa **seluruh nilai yang dimasukkan, nilai yang lulus, dan nilai yang remedi**.
